# Dataset

This directory contains the synthetic dataset used by the thesis notebooks.

- File: `synthetic_liver_cancer_dataset.csv`
- Rows: 5,000
- Columns: 14
- Target: `liver_cancer`
- Positive prevalence: approximately 21.8%
- Data type: fully synthetic; no real patient records

## Source

Kaggle: **Predict Liver Cancer from & Clinical Features**  
https://www.kaggle.com/datasets/miadul/predict-liver-cancer-from-and-clinical-features

The Kaggle data card states that the dataset is released under **CC0 1.0 Universal**.

## Important

The dataset is intended for academic / methodological experimentation. Results obtained on synthetic data should not be interpreted as evidence of clinical performance.
